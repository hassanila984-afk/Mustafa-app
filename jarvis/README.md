# JARVIS — مساعد صوتي

صفحة مستقلة (`jarvis/index.html`) بيها هولوگرام جارفس، تسمعك بالمايك، وترد بالصوت بالعربي أو الإنگليزي. وإذا سكتت تبقى تنتظر لحد ما تگول اسمه «جارفس».
تحتاج تنفتح كصفحة عادية (مو داخل claude.ai)، لأن claude.ai يمنع المايك داخل صفحاته.

جارفس يحچي ويا Claude عن طريق Google Apps Script، وهذا يخلي مفتاح الـAPI مخفي ومحفوظ عند Google وما يطلع بالصفحة أبد.

## 1. مفتاح Anthropic API
1. ادخل على https://console.anthropic.com وسوّي حساب.
2. اشحن رصيد من **Billing**. الاستخدام بالدفع حسب الاستعمال، والمحادثات الصوتية قصيرة فكلفتها قليلة.
3. من **API Keys** اضغط **Create Key** وانسخ المفتاح (يبدي بـ`sk-ant-`).

## 2. الـrelay بـGoogle Apps Script
1. ادخل على https://script.google.com واضغط **New project**.
2. امسح الكود الموجود، والصق محتوى الملف `jarvis/relay/Code.gs`، واضغط حفظ.
3. من **Project Settings** (أيقونة الترس) ← **Script properties** ← **Add script property**، ضيف:
   - `ANTHROPIC_API_KEY` = المفتاح اللي نسخته
   - `PASSCODE` = أي كلمة سر تختارها، مثلاً `hero-jarvis-2026`
   - (اختياري) `MODEL`: الافتراضي `claude-opus-5-5`. إذا تريد أرخص وأسرع، حط `claude-haiku-5-5`.
4. اضغط **Deploy** ← **New deployment** ← اختار النوع **Web app**:
   - **Execute as:** Me
   - **Who has access:** Anyone
5. اضغط **Deploy**، واسمح بالصلاحيات، وانسخ **Web app URL** (ينتهي بـ`/exec`).

> كلمة السر هي اللي تمنع غيرك يستخدم رصيدك. لا تشاركها ويا أحد.

## 3. افتح جارفس
- بعد ما ينضاف هالمجلد للفرع `main`، يصير الرابط:
  `https://hassanila984-afk.github.io/Mustafa-app/jarvis/`
  (هذا إذا GitHub Pages شغّال للمستودع من الفرع `main`.)
- أول مرة تطلع الإعدادات: الصق رابط الـrelay وكلمة السر، واكتب شوية عن نفسك وشغلك حتى جارفس يعرفك. اضغط **افحص الاتصال** وبعدها **حفظ**.
- اضغط «اضغط حتى يصحى جارفس»، واسمح للمايك. بعدها احچي عادي:
  - يرد بالصوت، وبعدين يرجع يسمعك بنفسه.
  - إذا سكتت حوالي دقيقة ينام. گول **«جارفس»** فيصحى.
  - گول «English» أو «عربي» حتى تغيّر لغة السماع.

## ملاحظات
- **المتصفح:** يشتغل على Chrome وEdge وSafari. Firefox ما يدعم سماع الصوت.
- **الصوت:** جارفس يختار أحسن صوت بجهازك. أقرب صوت لجارفس الفلم:
  - على الآيفون: نزّل **Daniel (Enhanced)** من الإعدادات ← تسهيلات الاستخدام ← المحتوى المنطوق ← الأصوات.
  - على الكمبيوتر: استخدم Edge واختار **Microsoft Ryan Online (Natural)**.
  - بعدها اختار الصوت من الإعدادات (أيقونة الترس) بالصفحة.
- **الحفظ:** المحادثة والإعدادات تنحفظ بنفس الجهاز والمتصفح فقط.
- **تعديل الكود:** إذا غيّرت `Code.gs`، لازم تسوي **Deploy ← Manage deployments ← Edit ← New version** حتى يطبق التعديل.
